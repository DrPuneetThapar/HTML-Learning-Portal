About the HTML Learning Portal

A self-contained, classroom-ready platform for teaching HTML to undergraduates — built entirely with static files, so it can be hosted anywhere with no backend.

About the creator

Dr. Puneet Thapar

Associate Professor, and Startup, Innovation and Entrepreneurship Coordinator, School of Computing and Artificial Intelligence, Lovely Professional University, Punjab.

What's inside

  • 43 topics across three units — from how the Internet works, through semantic HTML and forms, to CSS layout, animation, and responsive design.
  • 405+ runnable, copyable code examples across the tutorials.
  • 22 hands-on practice exercises — basic, advanced, and "debug the code" challenges — in a Monaco-powered live editor (the same engine behind VS Code).
  • 129 quiz questions with instant feedback, retake history, an optional timer, and per-unit or mixed-topic challenge modes.
  • A searchable reference of 86 common HTML tags, plus a 60-term glossary of web development jargon.
  • Three tiered project briefs with requirements checklists and grading rubrics, for real project-building practice.
  • Downloadable exam study guide PDFs (one per unit) with condensed notes and practice questions with answers.
  • One search box (press / anywhere) across every topic, quiz, tag, and glossary term.
  • A personal review list ("Still confused?" flagging), notes per topic, and a printable progress report.
  • Works offline after your first visit, and can be installed like an app on desktop or mobile.
  • Progress tracking, badges, and bookmarks that persist in your browser.

How progress tracking works

Your completed topics, quiz scores and full attempt history, bookmarks, notes, and topics flagged for review are all saved to your browser's local storage under a single key. Nothing is sent to a server — it's private to your device and this browser. Clearing your browser data will reset your progress.

Technology

HTML5 & CSS3

Semantic, hand-written markup and a custom design system — no framework CSS overrides needed beyond Bootstrap's grid.

Vanilla JavaScript

No build step, no framework — plain ES6+ modules loaded directly by the browser.

Bootstrap 5

Grid, navbar, and responsive utilities, layered under a custom visual theme.

Font Awesome

Iconography throughout the navigation, feature cards, and toolbars.

Monaco Editor

The same code-editing engine as VS Code, loaded from CDN for the Playground and Practice pages.

JSON data files

All tutorial, quiz, and reference content is authored as JSON in /data, then embedded as plain JavaScript in /js so the whole site runs from static files with no fetch requests.

Exam study guides

Condensed, downloadable PDFs for exam revision — a quick-reference summary of every topic in the unit, plus exam-style practice questions (short answer, differentiate-between, write-the-code, true/false) with a full answer key.

Using this in a classroom

Host the folder on any static file server (GitHub Pages, Netlify, a school's web server, or even a local python -m http.server). Every page works standalone — link students directly to a specific module with tutorial.html?topic=lists, for example.
